### 🇬🇧 English Version

# Zakázkovna - Order Management System

A professional console-based application designed for efficient management of business orders. Developed as a semester project for the **Czech University of Life Sciences Prague (ČZU)**.

## Features
* **Order Management**: Add, list, and edit business orders.
* **Configuration**: Manage user profiles and application settings via JSON.
* **Data Storage**: Reliable data handling using CSV and JSON formats.
* **Architecture**: Clean project structure following professional development standards.

## Project Structure
* **App/**: Contains the standalone executable (`.exe`) and the `Database/` folder with data files.
* **Source/**: Full C# source code, including `Models`, `Services`, and `Utils`.
* **Zakázkovna.sln**: Visual Studio Solution file for easy project access.

## Tech Stack
* **Language**: C#
* **Framework**: .NET 9.0
* **Data**: JSON, CSV

### 🇨🇿 Czech Version

# Zakázkovna - Systém pro správu zakázek

Profesionální konzolová aplikace určená pro efektivní správu obchodních zakázek. Vyvinuto jako semestrální projekt na **České zemědělské univerzitě v Praze (ČZU)**.

## Funkce
* **Správa zakázek**: Přidávání, výpis a úprava obchodních zakázek.
* **Konfigurace**: Správa uživatelských profilů a nastavení aplikace přes JSON.
* **Ukládání dat**: Spolehlivá manipulace s daty pomocí formátů CSV a JSON.
* **Architektura**: Čistá struktura projektu odpovídající profesionálním standardům vývoje.

## Struktura projektu
* **App/**: Obsahuje samostatný spustitelný soubor (`.exe`) a složku `Database/` s datovými soubory.
* **Source/**: Kompletní zdrojové kódy v C#, včetně složek `Models`, `Services` a `Utils`.
* **Zakázkovna.sln**: Soubor řešení Visual Studio pro snadný přístup k projektu.

## Použité technologie
* **Jazyk**: C#
* **Framework**: .NET 9.0
* **Data**: JSON, CSV
